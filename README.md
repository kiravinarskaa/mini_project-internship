# InternReady – Student Internship Platform

InternReady is a modern internship preparation and discovery platform designed for university students, beginners looking for internships, students exploring career paths, learners who are preparing for technical interviews.  
The website helps students evaluate their internship readiness, track important technical and soft skills, explore beginner-friendly internship opportunities, and follow structured career roadmaps.

The main goal of the project is to simplify the internship preparation process for students who may not know where to begin or which skills they need to improve before applying.

---

## Features

### 1. Readiness Checker
Students can complete a preparation checklist to calculate their internship readiness score.  
The system provides instant visual feedback using progress bars and readiness percentages.

### 2. Skills Tracker
The platform allows students to select their existing skills in areas such as:

- Web Development
- Data Analysis
- Cybersecurity
- UI/UX Design
- Soft Skills

The website displays:
- Selected skills
- Missing skills
- Skill categories

### 3. Internship Opportunities
Students can browse beginner-friendly internships by category:
- Web
- Data
- Cybersecurity
- Design

Users can:
- Filter internships
- Save internships
- Apply through a popup application form

### 4. Career Roadmaps
The platform includes visual learning roadmaps for different career paths:
- Cybersecurity
- Web Development
- Data Analysis
- UI/UX Design

Each roadmap provides:
- Learning steps
- Suggested technologies
- Resource links
- Career progression flowcharts

### 5. Interview Preparation
Students can practice common internship interview questions with expandable answer tips and guidance.
